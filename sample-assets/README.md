# Sample Assets

These files are included for staff-led attendee installs. They give the Hermes
Omni demo a ready-to-use image, PDF, and video without requiring internet access
or a separate asset bundle after the repo is cloned.

| File | Use |
|---|---|
| `gb10-board-image.png` | Upload first and ask the model to describe the image. |
| `gb10-partner-overview.pdf` | Upload second and ask for a short summary and key facts. |
| `gb10-demo-walkthrough-1080p.mp4` | Upload third and ask the model to describe what happens in the video. |

Suggested prompts:

```text
Describe this image and call out the main hardware elements you can see.
```

```text
Summarize this PDF for a partner evaluating a GB10-class local AI system.
```

```text
Describe what happens in this video and list the main demo steps.
```

```text
Can this host reach nvidia.com?
```
